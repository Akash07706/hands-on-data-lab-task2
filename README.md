# Task 2 - Hands-On Data Lab Implementation

This project practises a basic data analysis workflow with Python.

## Files
- main.py: analysis script
- student_performance_lab.csv: synthetic sample dataset
- student_performance_with_bands.csv: processed dataset
- task2_data_lab.ipynb: notebook exercises
- study_hours_vs_exam_score.png: scatter plot
- requirements.txt: Python libraries

## Run
Install Python 3.10 or later. In Terminal run:
1. python -m pip install -r requirements.txt
2. python main.py

The dataset is synthetic and for educational practice only. Correlation does not prove causation.
